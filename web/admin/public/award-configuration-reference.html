Award JSON configuration

This reference describes the award definition accepted by the Activity API and Admin editor. The shared runtime validator is contracts/award-definition.ts. Unknown fields are rejected. API updates may send a partial object; creates and saved definitions require the required fields below.

The example is structurally valid, but its background object key is a placeholder. Upload a background image in Awards management and use the registered asset's object key before saving. The service checks that the background is registered and adjusts its pixel dimensions to the selected print profile.

Complete example

Copy this JSON as a starting point. Change the programme, code, text, thresholds, registered background asset, and layout for the award. 

{
  "programmeSlug": "field-day",
  "code": "FIELD-DAY-10",
  "name": "Field Day Ten",
  "description": "Reach ten contacts during Field Day.",
  "awardText": "For excellent operating",
  "category": "HUNTER",
  "achievementMetric": "QSO_COUNT",
  "condition": {
    "kind": "AND",
    "conditions": [
      { "kind": "QSO_COUNT", "operator": "GTE", "value": 10 },
      {
        "kind": "OR",
        "conditions": [
          { "kind": "UNIQUE_ENTITIES", "operator": "GTE", "value": 3 },
          { "kind": "ENTITY_TYPE", "values": ["MUNICIPAL_PARK"] }
        ]
      }
    ]
  },
  "levels": [
    { "id": "level-10", "name": "Ten contacts", "threshold": 10 },
    { "id": "level-50", "name": "Fifty contacts", "threshold": 50 }
  ],
  "backgroundAsset": {
    "kind": "BACKGROUND",
    "name": "Field Day background",
    "objectKey": "field-day/background.png",
    "mediaType": "image/png",
    "widthPx": 2481,
    "heightPx": 3508
  },
  "printSpec": { "page": "A4", "orientation": "PORTRAIT", "dpi": 300 },
  "template": {
    "elements": [
      { "kind": "AWARD_NAME", "x": 0.1, "y": 0.1, "width": 0.8, "height": 0.1 },
      { "kind": "AWARD_TEXT", "label": "Award text", "x": 0.1, "y": 0.2, "width": 0.8, "height": 0.1 },
      { "kind": "CALLSIGN", "x": 0.1, "y": 0.3, "width": 0.8, "height": 0.1 },
      { "kind": "PERSON_NAME", "x": 0.1, "y": 0.4, "width": 0.8, "height": 0.1 },
      { "kind": "DATE_OBTAINED", "x": 0.1, "y": 0.5, "width": 0.8, "height": 0.1 },
      { "kind": "MANAGER_NAME", "x": 0.1, "y": 0.6, "width": 0.8, "height": 0.1 },
      { "kind": "MANAGER_SIGNATURE", "x": 0.1, "y": 0.7, "width": 0.8, "height": 0.1 }
    ]
  }
}

Top-level fields

programmeSlug — required string
Slug of the programme that owns this award. Must not be empty.
code — required string
Stable, programme-scoped award code. Must not be empty.
name — required string
Display name shown to administrators and participants. Must not be empty.
description — optional string
Longer explanation of the award. Defaults to an empty string.
awardText — optional string
Short text printed below the award name. Defaults to an empty string and is limited to 200 characters.
category — required string
HUNTER or ACTIVATOR. Input is case-insensitive and stored uppercase.
achievementMetric — optional string
Summary metric: QSO_COUNT, ACTIVATION_COUNT, UNIQUE_CALLSIGNS, or UNIQUE_ENTITIES. Use these uppercase values. Defaults to QSO_COUNT.
condition — required object
Recursive eligibility rule. See Condition kinds.
levels — required array
One or more thresholds. Each item has a non-empty string id, non-empty string name, and finite numeric threshold greater than zero.
backgroundAsset — required object
Registered background image. kind must be BACKGROUND. Optional name is its display label. objectKey must identify an uploaded background; mediaType, when supplied, is image/png or image/jpeg; widthPx and heightPx, when supplied, are positive integers. The server verifies the registered object key and computes print-ready dimensions.
printSpec — optional object
page is A4 or LETTER; orientation is PORTRAIT or LANDSCAPE; dpi is an integer from 150 through 300. Defaults are A4, portrait, and 300 DPI.
template — required object
Contains the certificate elements array. Every required element kind must appear at least once; supported optional kinds may be added.
signatureAssetId — optional string or null
Registered signature asset to use when issuing a certificate. Non-null values must be non-empty and identify a signature asset.
managerName — optional string
Manager name used as the certificate default when a request does not provide one.
effectiveFrom — optional timestamp string
ISO-compatible timestamp used when publishing. Leave it out of a draft unless needed.
awardId — optional string
Existing award identifier used when editing a draft. Omit when creating a new award.
expectedVersion — optional positive integer
Optimistic concurrency token for creating a new draft revision from a published award. It is not used for an ordinary draft create or update.

Condition kinds

  • AND / ALL and OR / ANY contain a non-empty conditions array.
  • NOT contains one nested condition.
  • ENTITY_TYPE contains a non-empty values array of entity type codes.
  • QSO_COUNT, ACTIVATION_COUNT, UNIQUE_CALLSIGNS, UNIQUE_ENTITIES, and FIELD compare a numeric fact to value. FIELD also requires a non-empty fact name.

Numeric conditions accept finite JSON numbers or numeric strings. operator may be GTE, GT, EQ, LTE, or LT; it defaults to GTE. Conditions may be nested to 32 levels.

Certificate template elements

Every element has a supported kind and normalized x, y, width, and height coordinates. Coordinates range from zero to one; width and height must be greater than zero, and the rectangle must fit inside the page.

  • Required: AWARD_NAME, CALLSIGN, PERSON_NAME, DATE_OBTAINED, MANAGER_NAME, and MANAGER_SIGNATURE.
  • Optional: AWARD_TEXT and CUSTOM_TEXT.
  • label is optional except for CUSTOM_TEXT, where it must be non-empty.

Fields managed by the service

These returned fields are not accepted in create or update input:

  • id, positive integer version, and revisionOf identify a stored award version.
  • status is one of DRAFT, UNDER_REVIEW, APPROVED, CHANGES_REQUESTED, PUBLISHED, or RETIRED. Change it through the submit, review, publish, and retire actions.
  • createdAt, updatedAt, submittedAt, reviewedAt, publishedAt, and retiredAt are service-generated timestamps.
  • printReadiness is calculated from the selected background and print profile.

Unknown fields are rejected so a misspelling cannot be silently saved.

Returned background assets may also contain service-managed identifiers, SHA-256 hashes, storage backend, bucket and endpoint, content status, content size, and creation or storage timestamps. These fields are accepted only while the service validates a merged stored record; clients must not send them in create or update input.
